# Importação da baseline v0.6

Esta branch importa a baseline técnica `A_Palavra_PWA_v0_6.zip` recebida no dossiê consolidado.

## Origem

- Produto: A Palavra — Aprendendo as Escrituras
- Baseline: v0.6
- Importação feita sem alterar os projetos Palavra Viva.
- O README original do repositório foi preservado.

## Estado

A baseline contém o leitor bíblico PWA, Bíblia N4 local, busca, progresso, favoritos, anotações, backup, manifesto e service worker.

Ainda não contém o motor de certificação dos 36 critérios, estudos certificados, auditoria dupla independente, teste Android físico ou publicação de produção.

## Bloqueio de distribuição

O áudio ambiente permanece apenas como parte da baseline para avaliação. A autorização de redistribuição pública ainda precisa ser comprovada antes de uma publicação pública.

## Atualização de distribuição

O áudio ambiente foi removido da distribuição pública nesta versão porque sua autorização de redistribuição ainda não foi comprovada. A remoção é reversível caso a documentação de direitos seja apresentada.

## Publicação

A publicação automática em GitHub Pages foi testada, mas o token da integração não possui o escopo específico para habilitar Pages (`Resource not accessible by integration`). O workflow foi removido para não manter uma execução quebrada. A aplicação permanece estática e pode ser publicada quando Pages for habilitado pelo proprietário ou em outro provedor estático.
